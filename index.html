Features

各项功能详细介绍

五大核心模块，覆盖「素材获取 → 内容填写 → 多平台发布 → 数据回收」的完整运营闭环

📊

① 工作台

  • 账号矩阵看板：8 平台 × 多账号的授权状态一屏总览
  • 数据统计：素材数 / 账号数 / 已授权数实时统计
  • 运营提示：根据当前状态给出下一步操作建议
📥

② 素材下载

  • 链接解析：粘贴抖音 / B 站 / 小红书 / 快手分享链接即可解析下载
  • 内外网双通道：国内平台直连，海外平台走系统代理
  • 下载进度：实时回传进度，完成后自动进入素材库
🚀

③ 一键发布（核心）

  • 自动上传视频：CDP 注入文件到平台上传控件，穿透 iframe，并自动代点「上传视频」按钮
  • 自动填表：等待标题/简介/话题控件渲染后自动填入，兼容 React/Vue 受控组件与富文本
  • 发布助手板块：各账号执行状态实时回传（✅ 已注入 / ⚠️ 需手动补）
  • 风险可控：自动点击发布为可选项且默认关闭，避免误发与触发风控
🏷️

④ 话题标签系统

  • 井号快捷键：Ctrl+Shift+3 光标处插入 #，选中文字则自动加 # 前缀
  • 批量粘贴：一次粘贴「城市摄影 街拍 #旅行」自动拆分，井号自动去除
  • 智能去重：忽略大小写去重，上限 24 个，实时计数
  • 预览与复制：生成 #标签 #标签 文本，一键复制到任意平台
📈

⑤ 数据中心

  • 一键获取数据：为所有已授权账号打开官方后台并读取真实数字
  • 六项指标：播放量 / 点赞 / 收藏 / 评论 / 分享 / 粉丝（万/亿/k 自动换算）
  • 汇总分类：全部账号总计 + 按平台归组小计 + 各账号明细表
  • 数据真实：直接读取官方后台页面显示值，不经任何第三方接口
👤

⑥ 账号管理

  • 会话隔离：每账号独立持久化分区，同平台多账号登录态互不干扰
  • 授权 / 退出 / 移除：退出登录保留账号记录，移除才清理
  • 导入 Cookie：从真实浏览器导入登录态，绕开内置浏览器风控
  • 安全策略：仅放行 http/https，拦截未知协议唤起
🎬

⑦ 素材库

  • 素材管理：列表展示大小与时间，支持预览播放、打开所在文件夹
  • 直接发布：从素材库一键送入发布流程
  • 发布记录：自动留存每次发布的标题、账号与素材
🔗

⑧ 数据后台直达

  • 携带登录态：一键打开各平台官方数据后台，免扫码
  • 多账号对比：可同时打开多个账号后台横向对比
  • 失败兜底：数据后台打不开时自动回退创作中心

三步式发布流程

1

选素材

从素材库选择，或粘贴平台分享链接解析下载；支持内外网双通道。

2

填一次

统一标题、简介与话题标签（可本地生成，也可用账号采集平台推荐话题）。

3

发全网

勾选账号矩阵，自动上传 + 自动填表，执行状态在「发布助手」实时回传。

技术实现要点

多账号会话隔离

基于 session.fromPartition('persist:平台-会话') 为每个账号创建独立持久化分区， Cookie 与 localStorage 完全隔离且重启保留，实现「同平台多账号同时在线」。

免手动上传文件

通过 Chrome DevTools Protocol 的 DOM.setFileInputFiles 将本地视频直接注入页面上传控件； 配合 pierce:true 穿透 iframe 查找，找不到控件时自动代点「上传视频」按钮。

注入式数据采集

在数据后台页面注入读取脚本，按关键词匹配播放/点赞/收藏等字段并解析「万/亿/k」单位， 通过 IPC 回传主窗口做汇总，全程不经第三方接口。

受控组件填表

针对 React / Vue 受控输入，使用原生 value setter 触发 input/change 事件； 富文本用 execCommand('insertText')，保证框架能接收到变更。

风控与稳定性

系统代理不可用时自动回退直连重试；未知协议链接一律拦截； 发布助手被 SPA 重渲染移除后自动挂回；自动点击发布默认关闭以规避平台风控。

工程化交付

Electron 33 + 原生 HTML/CSS/JS，electron-builder 打包为 NSIS 安装包与免安装绿色版； 上下文隔离 + preload 白名单 IPC，保障本地登录态安全。
